# McSurvey-Automator
McDVoice Survey Automator is a Python script that automates the submission of McDonald's customer satisfaction surveys on mcdvoice.com using the Selenium browser automation framework. This tool helps efficiently fill surveys while minimizing repetitive manual work.

Features

    Easy text file input for survey codes (one code per line, any filename).

    Fully automated browser form filling and submission using Chrome.

    Customizable survey replies; defaults select common, positive answers.

    Minimal console output and quiet browser logs for clean operation.

    Automatically maximizes browser and suppresses most system warnings.

    IMPORTANT: Processes up to five surveys per IP address per month following McDonald's survey rules.
